# LuCI page reference

See the [page-by-page LuCI reference](luci-pages/index.md) for every field, dependency, default, and misconfiguration risk. This page remains a compact menu index.

| Page | Purpose |
| --- | --- |
| User mode | Cloud, Router network and Agent services controls/status |
| Nexus Cloud (Developer mode) | Pairing, certificates and Cloud Direct/Relay modes |
| Overview | Services, Peers, routes, Relay, and public IPv6 summary |
| Quick Setup | First working deployment |
| Router Roles | Node, Relay, and Directory roles |
| Agent APIs & Protocols | SDK registration, auth, callbacks, MCP/A2A mappings |
| Local Agents | Local capability leases and public descriptors |
| Capability Routes | AFIB routes, metrics, and paths |
| Neighbors & Discovery | ARPX sessions, LAN and SVCB candidates |
| Peer Trust | Admission, revocation, Cards, and Directory evidence |
| Advanced Settings | ARPX, discovery, Relay, public IPv6, static routes |
| Static Peers | Explicit Peer inventory |
| Policy RIB | Identity admission, constraints, and route selection |

After **Save & Apply**, verify runtime state on the status pages instead of relying on the save notification alone.
