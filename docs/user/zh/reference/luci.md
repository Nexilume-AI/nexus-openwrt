# LuCI 页面参考

完整的字段说明、依赖关系、默认值和误配风险请查阅 [LuCI 逐页参考](luci-pages/index.md)。本页保留作菜单速查。

| 页面 | 用途 |
| --- | --- |
| User mode | Cloud、Router network、Agent services 开关及状态 |
| Nexus Cloud（Developer mode） | 配对、证书及 Cloud Direct/Relay 模式 |
| Overview | 服务、Peer、路由、Relay 与公网 IPv6 总览 |
| Quick Setup | 首次可用配置 |
| Router Roles | 选择 Node、Relay 和 Directory 角色 |
| Agent APIs & Protocols | SDK 注册、认证、Agent 回调、MCP/A2A 映射 |
| Local Agents | 本机 Agent 能力租约和公网连接描述符 |
| Capability Routes | AFIB 能力路由、指标和路径 |
| Neighbors & Discovery | ARPX 会话、LAN 与 SVCB 候选 |
| Peer Trust | 候选准入、撤销、Agent Card 与 Directory 证据 |
| Advanced Settings | ARPX、发现、Relay、公网 IPv6和静态路由 |
| Static Peers | 显式固定 Peer 清单 |
| Policy RIB | 身份准入、硬约束与路由选择策略 |

修改配置后使用 **Save & Apply**，然后回到状态页确认运行结果，而不只看保存提示。
